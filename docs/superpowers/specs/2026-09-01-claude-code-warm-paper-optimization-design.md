# Claude Code 暖纸张风格优化设计

## 背景

当前站点是直接部署到 GitHub Pages 的双页面静态个人作品站。首页把样式、Three.js 小票和背景动效全部内联在 `index.html` 中，项目详情页也包含独立的内联样式。现有视觉以深色霓虹、玻璃面板、星尘和动态光团为主，代码能够运行，但页面之间存在重复样式，首页单文件职责过多，测试只能对源码字符串做有限断言。

本轮优化采用经确认的 Claude Code App 暖纸张方向，在不引入框架和构建工具的前提下，统一视觉系统、拆分静态资源、降低持续动画成本，并补齐最低限度的测试、元数据和仓库文档。

## 目标

1. 将首页和 IndustrialSim 详情页统一为暖纸张视觉系统。
2. 把共享样式、首页小票和首页视觉效果从 HTML 中拆出，降低单文件维护成本。
3. 保持 GitHub Pages 直接部署能力，不新增运行时或打包依赖。
4. 改善移动端 CTA 一致性、减少无意义持续动画，并保留必要的降级路径。
5. 建立零第三方依赖的自动化测试与 GitHub Actions 验证。
6. 补齐 favicon、基础元数据、README 和本地工具目录忽略规则。

## 非目标

- 不大幅重写项目文案或调整信息架构。
- 不添加缺少可靠来源的 IndustrialSim 截图、演示或能力声明。
- 不引入 React、Vue、Astro、Vite、CSS 框架或第三方测试框架。
- 不重新实现 Three.js 小票物理系统。
- 不在本阶段发布、推送或创建拉取请求。

## 视觉系统

### 色彩

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 页面背景 | `#e9e5dc` | 暖米灰画布 |
| 次级背景 | `#f3f0e8` | 导航和弱分区背景 |
| 主面板 | `#faf8f2` | 纸白内容面板 |
| 主文字 | `#27241f` | 深褐黑正文和标题 |
| 次级文字 | `#716a60` | 灰褐辅助信息 |
| 强调色 | `#c96445` | 陶土橙主按钮和重点状态 |
| 辅助色 | `#72734f` | 低饱和橄榄状态和工程标签 |
| 边框 | `#cfc7ba` | 暖灰褐分隔线 |

所有组件只通过 CSS 自定义属性引用这些核心色彩，避免在页面专属规则中散落新的品牌色。

### 排版

- 主标题使用克制的系统衬线字体栈，形成 Claude 风格的编辑部式标题质感。
- 正文使用系统无衬线字体栈，优先保证中文可读性和加载稳定性。
- 协议、状态、标签和终端式信息使用系统等宽字体栈。
- 移除 Google Fonts 外部依赖，减少字体阻塞和第三方请求。

### 材质与动效

- 移除霓虹光团、星尘 Canvas、持续星尘动画和强玻璃模糊。
- 页面背景使用静态暖色径向渐变和轻量 CSS 网格，不启动持续绘制循环。
- 卡片改为实体纸张面板、细边框和低强度阴影。
- 主按钮使用陶土橙实体填充，次按钮使用纸面和边框层级。
- 保留 Three.js 小票及其可见性、页面可见性和减少动态效果控制，但纹理、背景和强调色改为暖纸张体系。
- 移动端所有首屏 CTA 保持完整按钮形态，不再把第三个 CTA 降级为普通文本。

## 代码架构

### 静态资源

新增以下文件：

- `assets/styles.css`：共享视觉令牌、基础样式、通用组件、首页规则、详情页规则和响应式规则。
- `assets/receipt.js`：Three.js 小票纹理、物理模拟、交互和生命周期管理。
- `assets/home-effects.js`：首页入场、卡片聚光和轻量指针效果；不再包含星尘 Canvas。
- `assets/favicon.svg`：使用简单的代码提示符与陶土橙生成可缩放站点图标。

首页增加 `body.home-page`，详情页增加 `body.project-page`。页面专属样式必须以对应 body 类限定，通用按钮、面板、焦点和排版规则保持共享。

### HTML

- 两个页面删除内联 `<style>`，统一引用 `assets/styles.css`；详情页使用相对路径 `../assets/styles.css`。
- 首页完整删除星尘 Canvas 和背景光团 DOM，页面背景只由 CSS 生成。
- 首页把小票脚本和视觉效果脚本改为带 `defer` 的外部脚本。
- Three.js 仍从现有 CDN 加载，并保持先于 `receipt.js` 执行。
- 保留协议流和架构图的内联 SVG，因为它们属于页面语义内容而不是通用资源。
- 首页“当前主页”链接改为站点根路径 `/`。
- 首页添加 `assets/favicon.svg` 引用，详情页添加 `../assets/favicon.svg` 引用。

## 行为和降级

### Three.js 小票

- Three.js 可用时保持桌面端拖拽和小票轮换行为。
- Three.js 不可用时显示现有静态小票信息，不阻断页面其余内容。
- `prefers-reduced-motion: reduce` 或移动端不启用高迭代交互物理效果。
- 小票离开视口或页面隐藏时停止调度帧和轮换定时器。
- 页面重新可见或小票重新进入视口时只调度必要帧，不恢复永久动画循环。

### 首页视觉效果

- 入场动画只执行一次，并遵守减少动态效果设置。
- 聚光和轻微倾斜仅在精确指针设备上启用。
- 不创建背景 Canvas，不启动永久 `requestAnimationFrame` 循环。
- JavaScript 不可用时，页面内容和主要链接仍完整可访问。

## 元数据与仓库维护

- 添加 SVG favicon，解决 `/favicon.ico` 缺失带来的浏览器请求问题。
- 更新两个页面的 `theme-color` 为暖纸张色值。
- 保留现有 canonical 和 Open Graph 文本；本阶段不伪造 `og:image`。
- 新增最小 `package.json`，只定义 `npm test`，不声明第三方依赖。
- 新增 `.gitignore`，忽略 `.claude/`、`.superpowers/` 和常见系统临时文件。
- 扩充 README，说明项目定位、目录结构、本地预览、测试和 GitHub Pages 发布方式。
- 新增 `.github/workflows/validate.yml`，在推送和拉取请求时使用当前 Node LTS 执行 `npm test`。

## 测试策略

测试使用 Node 内置 `node:test` 和 `assert`，放在 `tests/site.test.js`，不安装第三方依赖。

自动化测试覆盖：

1. 首页和详情页存在唯一主标题、canonical、favicon 和正确 body 页面类。
2. 两个页面正确引用共享样式，首页正确引用 Three.js、小票和视觉效果脚本。
3. 首页不再包含内联样式、星尘 Canvas、背景光团或永久星尘动画入口。
4. 小票脚本包含 Three.js 缺失降级、减少动态效果、页面可见性和视口可见性控制。
5. 首页内部项目链接和详情页返回链接指向有效的仓库内页面。
6. “当前主页”链接指向 `/`。
7. 所有带 `target="_blank"` 的链接同时包含 `noopener noreferrer`。

手工浏览器验收覆盖：

- 1440×1000 桌面首页和详情页。
- 390×844 移动首页和详情页。
- 页面无横向溢出。
- 页面无控制台错误或警告。
- 首页到详情页、详情页返回首页的导航正常。
- 暖纸张主题、按钮层级、焦点样式和小票降级可辨识。
- 减少动态效果模式下不出现持续或强烈动画。

## 实施顺序

1. 先建立会失败的新结构和行为测试。
2. 提取共享 CSS，并让两个页面切换到暖纸张视觉系统。
3. 提取小票与首页视觉效果脚本，移除星尘循环。
4. 更新 HTML 结构、元数据、favicon 和链接。
5. 添加 README、`.gitignore`、`package.json` 和 GitHub Actions。
6. 运行自动化测试并执行桌面、移动浏览器验收。

## 成功标准

- `npm test` 退出码为 0，GitHub Actions 使用同一命令。
- 两个页面不再包含内联 CSS，首页交互脚本不再内联。
- 页面不再创建星尘 Canvas 或永久背景动画循环。
- 桌面和移动端均无横向溢出、控制台错误或内部导航错误。
- Three.js 加载失败时仍显示静态小票。
- GitHub Pages 无需构建步骤即可继续发布全部页面与资源。
